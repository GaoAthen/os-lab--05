# Что делают команды:
`pvcreate` -  инициализирует физический диск или раздел для работы с LVM
`vgcreate` - объединяет один или несколько физических томов в единый виртуальный пул (группу томов)
`lvcreate` - нарезает из общей группы томов отдельные логические тома (аналоги обычных разделов диска)
`vgextend` - добавляет новые физические диски в уже существующую группу томов
`lvextend` - увеличивает размер уже существующего логического тома за счет свободного места в группе

# Зачем зачем в lvextend нужен ключ -r
Для автоматического изменения размера файла после увелечения логического тома (LV)

#  почему LVM — большое преимущество для сервера по сравнению с обычными разделами?
LVM предоставляет более высокую гибкость управления дисками нежели обычные разделы
